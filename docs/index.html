🖨️ Shopee Label Printer

Imprima etiquetas de envio da Shopee direto na sua impressora térmica

Recursos Download Documentação GitHub

O que é?

Um programa desktop para Windows que imprime etiquetas de envio da Shopee direto em modo RAW (bytes crus) para sua impressora térmica, preservando 100% da resolução original — sem conversão para PDF, sem reamostragem.

Python 3.10+ Zero Dependências Windows 10/11 MIT License

Recursos Principais

📦 Importação Flexível

ZIP, pasta ou arquivo TXT/ZPL avulso da Shopee

🔀 Separação Automática

Detecta e separa múltiplas etiquetas no mesmo arquivo

🖨️ Envio RAW

Bytes crus direto para impressora — sem perder qualidade

🔒 100% Local

Dados nunca são enviados a servidores (privacidade garantida)

📊 Log Profissional

Arquivo de logs para diagnóstico remoto

⚡ Interface Simples

GUI intuitiva em tkinter, sem complexidade

Download

Opção A: .exe Standalone (recomendado)

Não precisa instalar nada — é só executar.

📥 Baixar ShopeeLabelPrinter.exe

Opção B: Rodar com Python

Para desenvolvedores ou se preferir rodar do código-fonte:
