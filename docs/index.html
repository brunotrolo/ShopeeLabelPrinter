    3. Preview da etiqueta

    Importe um arquivo para ver o preview da etiqueta
    Impressão pelo navegador passa pelo driver do Windows. O navegador não consegue enviar bytes RAW para a impressora — essa é uma limitação dele, não do projeto. Para imprimir sem nenhuma perda de resolução, use a versão desktop, que fala direto com a impressora. Aqui a página já sai no tamanho físico exato (100 × 150 mm), o que costuma ficar bom, mas passa por rasterização do driver.
    Traço fino ou falhado? Imprimindo pelo navegador, o escurecimento não vem daqui: ajuste em Painel de Controle → Dispositivos e Impressoras → botão direito na impressora → Preferências de impressão, na opção de densidade ou darkness. Nesse caminho a impressora recebe uma imagem, e comando ZPL nenhum chega até ela.

    O seletor Modo de saída acima escolhe o formato do arquivo baixado: ZPL (nativo, para impressoras Zebra ou já em modo ZPL), TSPL (para a FY-1075 e outras que só entendem TSPL — descubra qual é a sua com o botão 🔧 Testar da versão desktop) ou PDF (para guardar ou imprimir por outro caminho). Os três vêm do mesmo bitmap do preview.

    O Reforço vale só para o arquivo baixado em ZPL ou TSPL — ele acrescenta comandos de calor e velocidade (^MD/^PR em ZPL, DENSITY/SPEED em TSPL) para quem for imprimir esse arquivo pela versão desktop. Se o código de barras parar de ser lido pelo celular, baixe um nível: calor demais faz as barras engordarem e colarem. Não se aplica ao PDF.

    Duas versões, mesmo núcleo

    As duas leem o ZIP, separam as etiquetas e decodificam o bitmap embutido com exatamente o mesmo algoritmo — o preview é idêntico nas duas. A diferença está só em como cada uma chega até a impressora.

    Como usar as duas juntas: confira as etiquetas aqui no navegador — de qualquer aparelho, sem instalar nada — e mande imprimir pela versão desktop quando quiser a fidelidade byte a byte na FY-1075.

    Requisitos

    • Versão web: Chrome 80+, Edge 80+, Firefox 113+ ou Safari 16.4+ (a leitura de ZIP usa DecompressionStream, nativo do navegador).
    • Versão desktop: Windows 10/11 e uma impressora térmica compatível com TSPL/ZPL a 203 DPI (referência: FY-1075).
